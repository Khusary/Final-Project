Built for Real Security

🔒

Hybrid AES-256 + RSA

Every file is encrypted with a unique AES-256-GCM key, which is itself encrypted using RSA-2048 before storage.

🧾

Digital Signatures

Each encrypted file is signed with RSA. Any tampering is detected and decryption is rejected automatically.

🛡️

SHA-256 Integrity Checks

Original and encrypted file hashes are verified at every step, before and after decryption.

✉️

OTP-Gated Decryption

Decrypting a file requires a one-time code sent to your verified email — no code, no access.

☁️

Encrypted Cloud Storage

Only ciphertext ever touches the cloud. Your original file never leaves the server unencrypted.

📊

Full Activity Logs

Every login, upload, download, and decryption is logged with IP and timestamp for full auditability.
